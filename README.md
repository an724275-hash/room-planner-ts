# План комнаты

Интерактивный 2D-планировщик на TypeScript и SVG. Можно менять размер комнаты и каждого предмета, добавлять и копировать мебель, перетаскивать её по сетке 10 см, поворачивать, удалять, отменять и повторять изменения. План сохраняется в браузере, импортируется из JSON и экспортируется в SVG или JSON. Всё работает локально, без аккаунта и внешних API.

[Открыть планировщик на GitHub Pages](https://an724275-hash.github.io/room-planner-ts/)

## Запуск

```powershell
npm install
npm run dev
```

Откройте адрес, показанный Vite. `npm test` запускает тесты геометрии, `npm run build` проверяет TypeScript и собирает статическую версию в `dist/`.

Клавиши: стрелки двигают выбранную мебель на 10 см; Delete удаляет; Ctrl+Z и Ctrl+Y отменяют и повторяют действие. На узком экране инструментальные панели идут последовательно над планом и под ним.

Это именно 2D-редактор, не инженерная CAD-система. Размеры предметов приблизительные; двери и окна пока не редактируются.
